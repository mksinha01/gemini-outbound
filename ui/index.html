Quick-Start Setup

Everything you need to get OutboundAI running.

First-Time Setup
  1. Open Supabase SQL Editor → run supabase_schema.sql
  2. Go to Settings → LiveKit → fill URL, API Key, Secret → Save
  3. Go to Gemini section → add API Key → Save
  4. Go to Vobiz section → fill credentials → Save → click Create SIP Trunk
  5. Go to AI Prompt → customise for your business → Save
  6. Go to Agent Profiles → create at least one agent
  7. Go to Single Call → test with your number
  8. Hear AI within 5–10 seconds ✅

Known Gotchas

🔴 Call drops at 60s — remove close_on_disconnect

🔴 Agent silent after 30s — use END_SENSITIVITY_LOW (full string)

🔴 No greeting — 3.1/2.5 models speak autonomously, skip generate_reply()

🔴 1008 error — use gemini-2.0-flash-exp

🔴 profiles.map error — run supabase_schema.sql first

🔴 SSL errors — certifi patch applied in agent.py and server.py
