💡 How it works

1. Enter the lead's phone number in E.164 format (e.g. +919876543210)

2. Optionally select an Agent Profile to use a specific voice, model, and prompt

3. Click Initiate Call — the AI will dial within seconds

4. The agent will greet the lead and follow the booking script

5. Call results appear in Call Logs automatically


💡 Tip

Make sure your SIP Trunk is configured in Settings and verified in Setup.

🔧 Quick-Start Setup
🚀 First-Time Setup
  1. Open Supabase SQL Editor → run supabase_schema.sql
  2. Go to ⚙️ Settings → LiveKit → fill URL, API Key, Secret → Save
  3. Go to Gemini section → add API Key → Save
  4. Go to Vobiz section → fill credentials → Save → click ⚡ Create SIP Trunk
  5. Go to ✏️ AI Prompt → customise for your business → Save
  6. Go to 🤖 Agents → create at least one agent profile
  7. Go to 📞 Single Call → test with your number
  8. Hear AI within 5–10 seconds ✅

⚠️ Known Gotchas

🔴 Call drops at 60s — remove close_on_disconnect

🔴 Agent silent after 30s — use END_SENSITIVITY_LOW (full string)

🔴 No greeting — 3.1/2.5 models speak autonomously, skip generate_reply()

🔴 1008 error — use gemini-2.0-flash-exp

🔴 profiles.map error — run supabase_schema.sql first

🔴 SSL errors — certifi patch is applied in agent.py and server.py
